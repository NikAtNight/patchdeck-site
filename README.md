# patchdeck-site

Marketing site for PatchDeck (github.com/NikAtNight/patchdeck).
Own brand, separate from the portfolio: dark editor palette built from diff
colors (add-green, del-red), JetBrains Mono display, diff-block hero signature.

Vite + React + TS + Tailwind 4. `npm run dev` / `npm run build`. Static dist/.
